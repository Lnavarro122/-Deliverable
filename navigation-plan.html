MenuOpen(open) is a function creates state synchronization between aria-expanded and data-state. The screen reads if it is open for aria-expanded and data-state is linked to the CSS and tells it if it is open or closed. This function connects the two.

Aria expanded is set to true when you "click"on the menu button.This creates activation when openIt checks if it is true or not.
